<h1 style="font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; color: #2c3e50; font-size: 32px; text-align: center;">
  🌡️ Temperature Converter - C++ Project
</h1>

<div style="border: 1px solid #dcdde1; box-shadow: 0 4px 10px rgba(0, 0, 0, 0.1); padding: 20px; margin-top: 20px; border-radius: 10px; background: linear-gradient(to right, #ffffff, #f7f9fb); font-family: 'Segoe UI', Tahoma, Geneva, Verdana, sans-serif; color: #2d3436; line-height: 1.6;">
  
  <p style="font-size: 16px;">
    <strong>📌 Objective:</strong> This program allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin scales using a simple console-based menu system written in C++.
  </p>

  <p style="font-size: 16px;">
    <strong>🛠️ Features:</strong>
  </p>

  <ul style="font-size: 15px; padding-left: 20px;">
    <li>Convert Celsius to Fahrenheit and Kelvin</li>
    <li>Convert Fahrenheit to Celsius and Kelvin</li>
    <li>Convert Kelvin to Celsius and Fahrenheit</li>
    <li>Loop-based menu for multiple conversions</li>
    <li>Exit option included</li>
  </ul>

  <p style="font-size: 16px;">
    <strong>💻 How It Works:</strong>
  </p>

  <ol style="font-size: 15px; padding-left: 20px;">
    <li>User selects an option from the menu.</li>
    <li>User inputs the temperature value.</li>
    <li>Conversion is performed based on the selected option.</li>
    <li>Output is displayed and user is returned to menu unless they choose to exit.</li>
  </ol>

  <p style="font-size: 16px;">
    <strong>📎 Example:</strong><br>
    If the user selects "Convert Celsius to Fahrenheit and Kelvin" and enters 25,<br>
    Output will be:<br>
    Fahrenheit: 77°F<br>
    Kelvin: 298.15K
  </p>

  <p style="font-size: 16px;">
    <strong>🧠 Concepts Used:</strong> Loops, Switch Statements, Functions, Input/Output, Arithmetic Operations
  </p>

  <p style="font-size: 16px;">
    <strong>📂 File:</strong> <code>temperature_converter.cpp</code>
  </p>

  <p style="font-size: 16px;">
    <strong>🎓 Suitable For:</strong> Beginners learning C++ basics and working with simple projects
  </p>
</div>
